# Notices

This repository contains only text and scripts written for it. It includes no third-party code, no console-maker SDK
material, no firmware and no game data.

The reference files name public sources (pspsdk and the pspdev toolchain, PPSSPP's source code and hardware articles,
vfpu-docs, uOFW, PSPTEK, Yet Another PSP Documentation, the Media Engine samples by mcidclan, the source code of the
ARK custom firmware for the calls it offers to homebrew) by name and URL so that readers can check them; nothing of them is
copied here beyond short identifiers such as function, register and file names. Each source keeps its own licence.

`docs/DEPENDENCIES.md` and `scripts/doctor.py` name tools by their official download pages. Nothing is bundled: users
download them on their own machine, under their own licences, after the agent asks.

Measurements marked `[measured: ...]` were taken by SandstoneDev on their own consoles.
